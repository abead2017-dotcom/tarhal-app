# جاهزية المتاجر — ترحال

هذه قائمة بالموانع الخارجية التي يجب إغلاقها قبل إصدار نسخة المتاجر. إعداد الملفات وحده لا يعني أن التطبيق جاهز للنشر، ولم تُنشأ هنا مفاتيح أو بيانات دخول.

## موانع الإصدار

- **عنوان API عام عبر HTTPS:** توفير عنوان الإنتاج النهائي واختباره بشهادة TLS صالحة، ثم ضبط عنوان التطبيق العام عليه. لا يُقبل عنوان محلي أو HTTP غير مشفر.
- **مرسل Gmail موثّق:** تحديد عنوان Gmail الذي سيُستخدم مرسلًا، والتحقق من ملكيته وإعداده لإرسال رسائل التحقق.
- **كلمة مرور تطبيق Gmail كسرّ:** إنشاء كلمة مرور تطبيق لحساب الإرسال وإدخالها في مخزن الأسرار/إعدادات النشر المعتمدة فقط. لا تُكتب في المصدر أو مستندات المشروع أو حزمة التطبيق، ولا تُرسل عبر سجلّات أو قنوات عامة. يجب عدم استبدالها بكلمة مرور حساب Gmail العادية.
- **مفتاح Google Maps مقيّد:** توفير المفتاح المطلوب ثم تقييده بحسب معرّفات التطبيق وشهادات التوقيع وواجهات Maps المستخدمة، وتفعيل واجهات الخدمة اللازمة فقط. لا يُعد المفتاح جاهزًا بمجرد إنشائه؛ يجب ضبط القيود ومراجعة أي استخدام عام له.
- **حسابات المطور:** توفير حسابات Apple Developer وGoogle Play Console الفعّالة، وإكمال التحقق من هوية الجهة واتفاقيات المطور والضرائب/الدفع وأذونات أعضاء الفريق ومتطلبات التوقيع الخاصة بكل منصة.
- **اسم الجهة وبيانات الدعم:** اعتماد الاسم القانوني للجهة المالكة/المشغّلة وبريد دعم صالح ورقم أو وسيلة تواصل مناسبة، وإدراجها في سياسة الخصوصية وبيانات المتجر.
- **مراجعة واعتماد سياسة الخصوصية:** استكمال صفحة المسودة في التطبيق، والتحقق من ممارسات البيانات الفعلية ومن متطلبات الأنظمة ذات الصلة، ثم اعتماد النص من الجهة المسؤولة. النص الحالي مسودة غير نهائية.
- **إقرارات المتاجر:** استكمال إقرارات الخصوصية وسلامة البيانات لكل متجر بناءً على تدفق البيانات والتنفيذ الفعلي، بما يشمل الحساب والبريد، بيانات الرحلات، الموقع الدقيق/المستمر للسائق، ومشاركة البيانات مع مزودي الخرائط والبريد. يجب مطابقة الأذونات ووصف استخدامها مع سلوك التطبيق.
- **رابط حذف عام:** نشر صفحة عامة ثابتة عبر HTTPS تشرح كيفية طلب حذف الحساب والبيانات، وإضافة رابطها إلى قائمة التطبيق في Google Play وأي موضع يطلبه المتجر. يجب أن يكون الرابط متاحًا للمراجعين والمستخدمين دون تسجيل دخول، وأن يعرض خطوات اتصال فعّالة.

## إعدادات المشروع الموجودة هنا

- `eas.json` يعرّف ملفات تعريف تطوير ومعاينة وإنتاج لـ EAS دون تغيير معرّفات iOS/Android.
- صفحة الخصوصية داخل التطبيق مسودة عربية، وليست بديلًا عن مراجعة قانونية أو صفحة حذف عامة منشورة.
- لا تتضمن هذه التغييرات عناوين إنتاج أو مفاتيح Maps أو بيانات Gmail أو حسابات مطور، ولا تنفذ بناءً أو رفعًا أو إرسالًا إلى المتاجر.
